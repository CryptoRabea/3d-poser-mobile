# Preset Poses Guide - C.R.G 3D Poser

## Overview

The C.R.G 3D Poser app includes a library of preset poses that provide quick starting points for character animation. These pre-configured poses are perfect for learning the app, creating animations quickly, or finding inspiration for custom poses.

## Available Preset Poses

### 1. **Standing** 🧍
- **Category**: Idle
- **Description**: Neutral standing pose with arms at rest
- **Use Cases**: Base pose for most animations, idle animations, transitions
- **Best For**: Starting point for custom poses

### 2. **Sitting** 🪑
- **Category**: Idle
- **Description**: Comfortable sitting position with bent legs and relaxed posture
- **Use Cases**: Seated conversations, rest animations, office scenes
- **Best For**: Creating sitting-based animations

### 3. **Idle** 😐
- **Category**: Idle
- **Description**: Relaxed idle stance with slight weight shift
- **Use Cases**: Waiting animations, ambient poses, character standing around
- **Best For**: Creating natural-looking idle loops

### 4. **Hands Up** 🙌
- **Category**: Action
- **Description**: Both hands raised above head - celebration or surrender pose
- **Use Cases**: Victory animations, celebration, surrender, reaching
- **Best For**: Action sequences and emotional expressions

### 5. **Thinking** 🤔
- **Category**: Emotion
- **Description**: Pondering pose with hand to chin and head tilted
- **Use Cases**: Thinking animations, contemplation, decision-making
- **Best For**: Character dialogue and emotional scenes

## How to Use Preset Poses

### Method 1: Quick Access Button (Recommended)
1. Load a 3D model using the **📦 Samples** or **📁 Import** button
2. Tap the **🎭 Presets** button in the top control bar
3. A dialog will open showing all available preset poses
4. Click **Apply Pose** on any preset to instantly apply it to your model
5. The pose will be applied with smooth animation

### Method 2: Using the Toolbar (Coming Soon)
- A compact toolbar with preset pose buttons will appear at the bottom of the screen
- Click any pose icon to quickly apply it
- Hover over icons to see pose descriptions

## Workflow Examples

### Example 1: Create a Standing-to-Sitting Animation
1. Load a sample humanoid model
2. Tap **🎭 Presets** and apply the **Standing** pose
3. Tap **🎬 Timeline** to open the animation editor
4. Record a keyframe at frame 0
5. Go back to presets and apply the **Sitting** pose
6. Record another keyframe at frame 30
7. Play the animation to see the smooth transition

### Example 2: Create a Celebration Animation
1. Load a model
2. Apply the **Hands Up** preset pose
3. Save this pose with a name like "Celebration"
4. Create variations by slightly adjusting the bone transforms
5. Save multiple celebration poses
6. Use the timeline to blend between them

### Example 3: Create a Thinking Loop
1. Load a model
2. Apply the **Thinking** preset pose
3. Record it as a keyframe at frame 0
4. Adjust the head rotation slightly and record at frame 20
5. Return to **Thinking** pose and record at frame 40
6. Play the animation to see a subtle thinking loop

## Troubleshooting

### Preset Won't Apply
- Ensure a model is loaded first
- Check that the model has bones/skeleton
- Try loading a sample model first

### Pose Looks Different Than Expected
- Different models may have different proportions
- Try adjusting the model scale using the sample models
- Manually fine-tune the pose using bone transforms

### Animation Doesn't Blend Smoothly
- Ensure keyframes are properly spaced
- Use easing functions for smoother transitions
- Increase the number of frames between keyframes
